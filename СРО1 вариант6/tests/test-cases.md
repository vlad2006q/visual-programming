# Тест-кейсы

| № | Проверка | Ожидаемый результат |
|---|---|---|
| 1 | Запуск приложения | Появляется таблица оценок |
| 2 | Добавление корректной записи | Новая строка появляется в таблице |
| 3 | Пустое поле | Отображается сообщение об ошибке |
| 4 | Балл `abc` | Сообщение о некорректном формате |
| 5 | Балл -1 или 101 | Запись не сохраняется |
| 6 | Поиск по имени/дисциплине | Таблица фильтруется |
| 7 | Фильтр группы/дисциплины | Остаются соответствующие строки |
| 8 | Удаление с подтверждением | Выбранная запись удаляется |
| 9 | Сохранение и повторный запуск | Данные загружаются из CSV |
| 10 | Расчёт среднего | Значение пересчитывается по видимым строкам |
