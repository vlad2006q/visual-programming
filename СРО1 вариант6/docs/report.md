## Цель работы
Получить практические навыки разработки графического интерфейса с использованием JavaFX, FXML и CSS, обработки пользовательского ввода и сохранения данных.

## Описание приложения
Student Grade Calculator — приложение для ведения журнала оценок студентов. Каждая запись содержит ФИО студента, группу, дисциплину и балл от 0 до 100. Реализованы добавление, редактирование и удаление записей, поиск, фильтрация и расчёт среднего балла.

## Технологии
Java 21, JavaFX Controls, FXML, CSS, Maven, CSV.

## Архитектура
`StudentGrade` представляет модель записи; `GradeService` отвечает за чтение и сохранение CSV; `MainController` управляет таблицей и фильтрами; `GradeFormController` проверяет поля формы. FXML-разметка отделяет интерфейс от логики приложения.

## Тестирование
Проверяются обязательные поля, целочисленный формат оценки, диапазон 0–100, поиск, фильтры, удаление и повторная загрузка сохранённых данных. Полный список тестов находится в `tests/test-cases.md`.
