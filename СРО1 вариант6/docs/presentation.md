# Презентация: Student Grade Calculator

1. **Титульный слайд:** СРО №1, вариант 6, ФИО и группа.
2. **Цель:** разработать журнал оценок студентов.
3. **Технологии:** Java 21, JavaFX, FXML, CSS, Maven, CSV.
4. **Функциональность:** добавление, редактирование, удаление, поиск, фильтры, средний балл.
5. **Архитектура:** модель StudentGrade, сервис GradeService, контроллеры окон.
6. **Главное окно:** вставить скриншот таблицы и фильтров.
7. **Форма оценки:** вставить скриншот формы добавления записи.
8. **Тестирование:** показать валидацию, поиск и сохранение данных.
9. **Вывод:** основные требования реализованы, приложению требуется локальная проверка перед сдачей.
