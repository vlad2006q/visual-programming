# Student Grade Calculator — вариант 6

Учебное JavaFX-приложение для ведения журнала оценок студентов.

## Функции
- просмотр оценок в таблице;
- добавление, редактирование и удаление записей;
- поиск по ФИО и дисциплине;
- фильтрация по группе и дисциплине;
- подсчёт среднего балла по видимым записям;
- проверка обязательных полей и баллов в диапазоне 0–100;
- сохранение данных в `data/grades.csv`.

## Требования
- JDK 21 или новее;
- Maven 3.9+.

## Запуск
В терминале из корневой папки проекта выполните:
```bash
mvn clean javafx:run
```

FXML-файлы находятся в `src/main/resources/kz/studentgrades/` и открываются в Gluon Scene Builder.

## Материалы отчётности
- `docs/Отчет_СРО_1_Вариант_6.docx` — редактируемый отчёт;
- `docs/Отчет_СРО_1_Вариант_6.pdf` — PDF отчёта;
- `docs/Презентация_СРО_1_Вариант_6.pptx` — презентация на 9 слайдов;
- `docs/Презентация_СРО_1_Вариант_6.pdf` — PDF-версия презентации;
- `docs/report.md` и `docs/presentation.md` — текстовые версии материалов.

## Перед сдачей
1. Впишите ФИО, группу и преподавателя в отчёт и презентацию.
2. Запустите приложение на компьютере и проверьте тест-кейсы из `tests/test-cases.md`.
3. Замените схематичные макеты на слайдах 6–7 презентации фактическими скриншотами приложения.
4. Сделайте не менее 8 осмысленных коммитов в процессе работы. Не подделывайте историю Git.
